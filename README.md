圆柱形药材烘干过程的传热传质模型

项目简介
这是我在2026年全国大学生数学建模竞赛中完成的项目。主要针对圆柱形中药材热风烘干过程，建立了一维径向的传热传质耦合模型，用数值仿真来模拟药材内部的温度和水分变化。

我主要负责的工作

1. 建立了基于傅里叶定律和菲克定律的圆柱坐标偏微分方程模型。
2. 因为显式差分容易不稳定，我采用了隐式差分格式来离散方程，并自己用 Python 编写了追赶法来求解三对角矩阵。
3. 在问题四中，用归一化坐标把移动边界转化成了固定区域求解，并设计了一个简单的消融分析，算出来尺寸收缩大约贡献了60%的烘干加速。
4. 做了网格无关性和时间步长收敛性验证，确保结果不是偶然算出来的。

文件结构
code 文件夹：问题一到四的求解代码，以及追赶法公共函数。
results 文件夹：跑出来的温度、水分浓度分布数据（Excel文件）。
figures 文件夹：画出来的一些关键结果图，比如温度分布云图、水分热力图等。

运行环境
Python 3.9，需要 numpy、pandas、scipy、matplotlib 这几个库。直接运行 solve1.py 到 solve4.py 就能跑出对应的结果。
